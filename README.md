# Student Life Under Pressure

A four-page, static student wellbeing site built with HTML and CSS.

## Run locally

Open `index.html` in a browser. The site has no build step or dependencies.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the site to GitHub Pages whenever changes are pushed to `main`. After the first workflow run succeeds, the site is available at:

https://utkarshdev01.github.io/pixel_persona/

If Pages has not been enabled for the repository, enable it in **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
